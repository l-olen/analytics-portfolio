# Кейс: Маркетинговая аналитика частной клиники

**Контекст:** Частная медицинская клиника, Ташкент. Реклама через Google Ads,
трекинг через GA4, лиды в AmoCRM.

**Задача:** Построить end-to-end аналитическую систему — от сырых данных API
до SQL-анализа воронки и выявления аномалий.

## Стек

- **Python** — ETL: выгрузка из Google Ads API, GA4 API, AmoCRM API
- **SQLite** — хранение исторических данных (12 месяцев)
- **SQL** — анализ воронки, тренды, оконные функции
- **Power BI** — дашборд

## Архитектура

```
Google Ads API ──┐
GA4 API        ──┼──► ETL (Python) ──► SQLite ──► SQL-анализ ──► Power BI
AmoCRM API     ──┘
```

## Структура

```
etl/            скрипты выгрузки (локально, не в репо)
sql/            SQL-запросы для анализа
    01_funnel                  воронка канал → лид → сделка
    02_channel_analysis        CTR, CPC, стоимость лида по каналу
    03_trends                  LAG/LEAD тренды, до/после запуска сайта
    04_audience_creative       возраст/пол, CTR по теме объявления (education-кейс)
data/
    demo.db     анонимизированная база (×коэффициент)
analysis/       ноутбуки и выводы
```

## Примечания по данным

- Конверсии Google Ads: используется разбивка по `conversion_action_name`,
  только формы с сайта (исключены звонки и Google Maps)
- Дата запуска нового сайта: 2026-06-23 (breakpoint в анализе трендов)
- Данные анонимизированы: числа умножены на случайный коэффициент
